# 文件规定

### 一、最直接可引用的规定

**《普通高等学校学生管理规定》（教育部令第41号）**

> **第二十条**　学校应当开展学生**诚信教育**，以适当方式记录学生学业、学术、品行等方面的诚信信息；

> **第五十条**　确定推荐免试研究生……等赋予学生利益的行为，应当建立公开、公平、公正的程序和规定，建立和完善相应的选拔、公示等制度；

> **第五十一条**　对有违反本规定及学校纪律行为的学生，学校可视情节轻重给予警告直至开除学籍的纪律处分。

### 二、推免资格本身对“诚实守信”的硬性要求

**《全国普通高等学校推荐优秀应届本科毕业生免试攻读硕士学位研究生工作管理办法（试行）》（教学〔2006〕14号）**

> **第十四条**　推免生遴选条件包括“**诚实守信**，学风端正，无任何考试作弊和剽窃他人学术成果记录”。
